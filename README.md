# Rajini 3D Digital Marketing Portfolio — Sample

## Run locally
You can simply open `index.html` in a modern browser, although some browsers may restrict ES modules from `file://`.

For the smoothest local preview:
- VS Code + Live Server, or
- any simple local HTTP server.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Select the `main` branch and `/ (root)`.
5. Save.

The site uses Three.js from jsDelivr CDN, so there is no large 3D library to upload.

## First things to customise
Open `script.js` and edit the `stations` array:
- About Me
- Projects
- Digital Skills
- Education
- LinkedIn

Replace the LinkedIn URL with your real profile.

## Concept
This is intentionally a smaller, portfolio-friendly interpretation of the interactive 3D portfolio idea:
- WASD / arrow-key driving
- Clickable 3D stations
- Portfolio information panels
- Mobile touch controls
- Portfolio map menu
- Lightweight procedural 3D scene
- GitHub Pages friendly
